Features

Custom Color Filters

Select from 13 spectrum tones, including Sky Blue, Amber, Vermilion, and Orange, with precise opacity controls to soften harsh light.

Screen Time Tracker

Tracks real active computer usage using idle-input detection, keeps hourly/daily/monthly history, and stores statistics for personalized usage recommendations.

Automated Scheduling

Supports fixed schedules and location-based day/night scheduling, with automatic preset switching and customizable checkpoints.

Hardware Auto-Detection

Controls laptop brightness through WMI and external monitors through DDC/CI, with AC/Battery preset switching and state restoration.

Smart Eye Rest Alerts

Provides 20-20-20 eye rests, posture resets, hydration reminders, and other habit prompts while active computer use is detected.

Lightweight & Native

Built completely in AutoHotkey v2 for minimal memory consumption, starting quietly in your Windows system tray.

Location-Based Scheduling

Use your location and local day/night state to switch between presets automatically, including midnight rollover handling.

Custom Preset Editor

Edit custom presets with a dedicated menu and dropdown, with Save, Discard, and Cancel prompts for unsaved changes.

Safe Settings Validation

Validates settings and preset data when loading so an edited or corrupted configuration can fall back to safe defaults instead of breaking startup.

Built-In Update Checker

Checks GitHub releases from inside the application and prompts you when a newer Filter Studio version is available.

Display Change Detection

Monitors screen updates and can notify you when Windows HDR or a graphics-driver update prevents the color filter from applying correctly.
