Features

Custom Color Filters

Select from 12 spectrum tones (Amber, Vermilion, Orange, Blue) with precise opacity controls to eliminate strain and harsh light.

Screen Time Tracker

Monitors hourly, daily, and monthly active computer usage to help build awareness and track healthier screen habits.

Automated Scheduling

Automatically adjust screen warmth and brightness levels according to customizable daily schedule checkpoints.

Hardware Auto-Detection

Seamlessly controls laptop screen brightness via WMI and external monitors via DDC/CI commands, including AC/Battery switching.

Smart Eye Rest Alerts

Integrates 20-20-20 eye rests, posture resets, and hydration reminders triggered only when active input is detected.

Lightweight & Native

Built completely in AutoHotkey v2 for minimal memory consumption, starting quietly in your Windows system tray.

Quick Toggle

Toggle the Filter Studio control panel from anywhere using:

Ctrl + Shift + F

Filter Studio is open-source software built for Windows using AutoHotkey v2.
